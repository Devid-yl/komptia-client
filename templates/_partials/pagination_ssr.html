NE JAMAIS dupliquer ce markup : tout pager côté serveur passe par ``{% module Pagination(page=..., total_pages=...) %}``. Le pendant client (listes AJAX) est ``static/js/pagination.js`` (même fenêtrage). , aria-current sur la page active, aria-label FR sur chaque contrôle, bornes via {% end %} {# ── Page précédente ‹ ── #} {% if current > 1 %}{% else %}{% end %} {# ── Numéros de page (fenêtrés) ── #} {% for it in items %} {% if it is None %} … {% elif it == current %} {{ it }} {% else %} {{ it }} {% end %} {% end %} {# ── Page suivante › ── #} {% if current < total_pages %}{% else %}{% end %} {# ── Dernière page ⏭ ── #} {% if current < total_pages %}{% else %}{% end %}
